# OpenAI 嵌入

把笔记内容转成用于语义搜索的向量，让你能用自然语言在资料库里找到意思相近的笔记。支持 OpenAI，也支持其他兼容 OpenAI 嵌入接口的服务。

## 开始使用

1. 在插件中心安装「OpenAI 嵌入」，再到插件页的「已安装」里打开开关。
2. 打开插件详情的「设置」，填写「API Key」和「模型地址」并保存。
3. 到「设置 → 嵌入模型」，在「OpenAI 嵌入」分组里选一个模型点「设为当前」。确认后 Tau 会先验证连接，通过后在「当前生效」里点「立即索引」。

「模型地址」写到 `/v1` 为止，比如 `https://api.openai.com/v1`；如果用别家服务，就填它提供的地址。默认提供 `text-embedding-3-small` 和 `text-embedding-3-large` 模型，向量维度以 Tau 实测为准。

## 常见问题

**会产生费用吗？** 会。生成向量按服务商的计费规则收费，索引笔记、检索提问都会调用嵌入接口。

**启用后笔记会自动建索引吗？** 不会。为了避免意外产生费用，新增或修改的笔记也需要在「设置 → 嵌入模型」里点「立即索引」才会更新。

**换嵌入模型会怎样？** 切换模型并确认后，Tau 会清除原有索引并按新模型重建，不同模型的向量不能混用。

**能用其他服务商吗？** 可以。只要它兼容 OpenAI 的嵌入接口，在插件设置里把「模型地址」改成它提供的地址即可。

## 小提醒

- 笔记内容会发送到所配置的模型服务，请确认服务商的数据政策符合你的要求。
- API Key 相当于账号凭证，不要发给别人，也不要贴在截图或问题描述里。
