# OpenAI 嵌入

把笔记内容转成向量，用于知识库的语义检索。支持 OpenAI，也支持其它兼容 OpenAI 嵌入接口的服务。设为当前模型后，就可以用自然语言在知识库里找到语义相近的笔记。

## 开始使用

1. 在插件中心安装「OpenAI 嵌入」，然后在插件页的「已安装」里打开开关，无需重启。
2. 进入本插件详情的「设置」，填写 API Key 和模型地址，点击保存。
3. 到应用「设置 → 嵌入模型」，在「OpenAI 嵌入」分组里选一个模型点「设为当前」。确认后会先验证连接，通过后在「当前生效」中点「立即索引」。

服务地址写到 `/v1` 为止，比如 `https://api.openai.com/v1`。用的是别家服务，就填它提供的地址。默认提供 `text-embedding-3-small` 和 `text-embedding-3-large` 两个模型，向量维度以应用实测为准。

## 常见问题

**会产生费用吗？** 会。生成向量按服务商的计费规则收费，索引笔记、检索提问都会调用嵌入接口。

**启用后笔记会自动建索引吗？** 不会。为了避免意外产生费用，新增或修改的笔记也需要在「设置 → 嵌入模型」中点「立即索引」才会更新。

**换嵌入模型会怎样？** 切换模型并确认后，应用会清除原有索引并按新模型重建，不同模型的向量不能混用。

**能用其它服务商吗？** 可以。只要它兼容 OpenAI 的嵌入接口，就在插件设置里把模型地址改成它提供的地址。

## 注意

- 笔记内容会发送到所配置的模型服务，请确认服务商的数据政策符合自己的要求。
- API Key 请妥善保管，别出现在截图或问题反馈里。
