# OpenAI 嵌入

將筆記內容轉為用於語意搜尋的向量，讓你用自然語言就能在資料庫中找到意思相近的筆記。支援 OpenAI，也支援其他相容 OpenAI 嵌入介面的服務。

## 開始使用

1. 在外掛中心安裝「OpenAI 嵌入」，再到外掛頁的「已安裝」裡開啟開關。
2. 開啟外掛詳情的「設定」，填寫「API Key」與「模型位址」並儲存。
3. 前往「設定 → 嵌入模型」，在「OpenAI 嵌入」分組裡選一個模型點「設為當前」。確認後 Tau 會先驗證連線，通過後在「當前生效」裡點「立即索引」。

「模型位址」填寫到 `/v1` 為止，例如 `https://api.openai.com/v1`；若使用其他服務商，請填寫對方提供的位址。預設提供 `text-embedding-3-small` 與 `text-embedding-3-large` 模型，向量維度以 Tau 實測為準。

## 常見問題

**會產生費用嗎？** 會。產生向量會依服務商的計費規則收費，索引筆記與檢索提問都會呼叫嵌入介面。

**啟用後筆記會自動建立索引嗎？** 不會。為避免意外產生費用，新增或修改的筆記也需要在「設定 → 嵌入模型」裡點「立即索引」才會更新。

**更換嵌入模型會怎樣？** 切換模型並確認後，Tau 會清除原有索引並依新模型重建，不同模型的向量不能混用。

**可以使用其他服務商嗎？** 可以。只要服務相容 OpenAI 的嵌入介面，在外掛設定裡把「模型位址」改為對方提供的位址即可。

## 小提醒

- 筆記內容會傳送至所設定的模型服務，請確認服務商的資料政策符合你的需求。
- API Key 相當於帳號憑證，不要發給別人，也不要貼在截圖或問題描述裡。
